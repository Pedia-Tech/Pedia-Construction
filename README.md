# Prime Core Rebar

> **Precision Structural Rebar Detailing, BBS & Estimation Platform**

A cutting-edge, light architectural web application engineered for structural engineering consultancies, steel fabricators, and general contractors.

---

## 🏗️ Core Engineering Capabilities

- **Rebar Detailing**: Clash-free 2D/3D shop drawings prepared for site ironworkers.
- **Bar Bending Schedule (BBS)**: Standardized schedules conforming strictly to ACI 318, BS 8666, IS 2502, and Eurocode 2.
- **Rebar Quantity Estimation**: Granular takeoffs, scrap minimization algorithms, and mill-order optimization.
- **Interactive 3D Detailing Lab**: Real-time rebar weight formulas ($W = \frac{D^2}{162} \times L \times Q$) with interactive member inspection.
- **BIM LOD 400 Visualization**: Interactive 3D structural viewer with explode, rebar cage, and concrete envelope toggles.

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **3D Graphics & WebGL**: [Three.js](https://threejs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visuals**: High-resolution on-site rebar and structural execution imagery

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
